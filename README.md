# 🏢 StudioSpace

### Studio & Space Management Platform

StudioSpace is a modern web application designed to manage studio spaces and related information through a clean, responsive, and user-friendly interface. It demonstrates modern web development practices using Next.js, React, TypeScript, and MongoDB.

🔗 **Live Demo:** [Visit StudioSpace](https://studio-space-client-chi.vercel.app/)

📂 **GitHub Repository:** [studio-space-client](https://github.com/Al-aminCodes/studio-space-client)

---

## ✨ Key Features

- 🔐 **Authentication System** — User authentication and session management with Better Auth.
- 🏢 **Studio & Space Management** — Manage studio or space information through CRUD operations.
- ➕ **Create Records** — Add new studio or space information using forms.
- 📋 **Read Records** — View and explore saved information.
- ✏️ **Update Records** — Edit existing information.
- 🗑️ **Delete Records** — Remove existing records when necessary.
- 👤 **User Profile** — Access account information and profile-related options.
- 🧭 **Responsive Navigation** — Navigation bar with account-related menu options.
- 🌗 **Theme Switching** — Light and dark theme support.
- 🔔 **Toast Notifications** — Display feedback for supported user actions.
- 📱 **Responsive UI** — Layout designed for desktop, tablet, and mobile screens.
- 🧩 **Reusable Components** — Modular UI components for maintainable development.

---

## 🔄 CRUD Operations

StudioSpace demonstrates the four fundamental operations used to manage application data.

| Operation | Description |
|---|---|
| **Create** | Add a new studio or space record. |
| **Read** | Retrieve and display existing records. |
| **Update** | Modify the details of an existing record. |
| **Delete** | Remove a record from the application. |

These operations form the core of data management and help demonstrate how a full-stack application handles records throughout their lifecycle.

## 🔐 Authentication & Data Management

StudioSpace uses Better Auth for authentication and MongoDB integration.

The application is designed around authenticated user experiences and studio or space data management.

Depending on the configured implementation, CRUD operations should validate submitted data and enforce appropriate authorization rules. Users should only be permitted to modify or delete records when authorized by the application.

For production deployments, keep secret keys private and configure authentication URLs and database connections for the production environment.

## 🌐 Deployment

StudioSpace is available online through Vercel.

**Live Application:** [https://studio-space-client-chi.vercel.app/](https://studio-space-client-chi.vercel.app/)

To deploy your own instance:

1. Push the project to GitHub.
2. Import the repository into [Vercel](https://vercel.com/).
3. Configure the required environment variables.
4. Deploy the application.
5. Test authentication, database connectivity, and CRUD operations in the deployed environment.

For more information, see the [Next.js deployment documentation](https://nextjs.org/docs/app/getting-started/deploying).
